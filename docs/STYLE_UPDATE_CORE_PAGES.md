# YiJian 核心页风格更新

2026-10-08。第一阶段实现任务中心与位点判读，核心页确认后再推广到其余页面。当前未部署生产。

## 设计与交互

- 保留品牌绿色，以中性灰白背景、轻边框和排版建立层级；侧栏 224px，页面标题 24px / 600，正文 14px，核心表格 13px。
- 任务中心展示任务名称和编号，主操作移至页头；最近一批任务（最多 100 个）的状态概览可快速筛选。任务状态使用圆点，临床分类继续使用独立标签，运行阶段与费用语义保持原样。
- 结果类型使用横向导航，移除工作区内嵌套卡片。工具栏集中列筛选、个人筛选视图、导出、列显示和密度控制；身份与回报列不能隐藏，所有筛选仍由原浏览器数据引擎执行。
- CSS 宽度至少 1440px 时，420px 详情区与表格并列；更窄屏幕使用抽屉，支持焦点约束、Escape 关闭和焦点恢复。详情分为概览、注释、证据、评定，切换标签保留正在编辑的内容。
- CNV 计算器复用详情区，五个评分章节直接展开并提供章节导航。分数条使用中性色，避免把致病方向的正分标为操作成功。
- 初评失败与证据限制直接显示；完整证据可用性与资源版本统一放入“评估信息”。流式初评、缓存隔离和取消机制保持不变。

## 本地设计预览

```powershell
node scripts/style-preview/server.cjs
```

打开 `http://127.0.0.1:4173/tasks/preview-task?tab=snv-indel`，通过预览浮条切换任务列表、位点判读和明暗主题。

预览复用真实页面组件，使用明确标注的合成数据，包括 55,393 条 SNP/InDel 以及两类 CNV 的分页示例。测试 API 仅在该独立 Vite 服务中替换，不加入 Next.js 路由，不连接生产写接口，也不绕过应用认证。预览的筛选与分页行为用于设计评审，不能代替真实 Parquet 性能或生产读写验收。预览工具沿用 Vitest 所依赖的 Vite，无须安装额外依赖。

## 接口与验证

- 后端接口和临床规则未修改。任务列表类型增加可选 `name`，保留后端已提供的名称；未提供时显示流程名称。名称变更参与列表刷新比较。
- 新增回归覆盖：切换证据标签保留判读草稿、早先位点保存完成后不覆盖当前位点理由。原有筛选方案保存、版本冲突恢复测试继续保留。
- 类型检查和生产构建通过；103 项测试通过，1 项需要外部参考包的性能测试按原配置跳过。55,393 行 Worker 回归通过，单批结果不超过 1,000 行。
- 浏览器已验证合成数据筛选、分页区域、宽屏详情不遮挡表格、CNV 五章节、窄屏抽屉与键盘焦点、任务搜索及状态筛选、列显示和行密度、任务中心深色主题。真实归档数据的端到端初评、生产保存及其余断点/页面的暗色验收仍需在核心页设计确认后的联调中完成。
