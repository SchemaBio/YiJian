# 浏览器自动初评与置顶：实施和验收记录

更新：2026-10-07。当前修订尚未完成生产验收，不能视为八类临床证据全部齐备。

## 已实现

- 评估上下文固定任务、attempt、数据集、HPO、规则和证据包版本。人工显式重评；版本更新不静默改变判读。
- 浏览器 Worker 全量逐批评估，完成后再查询和分页。候选上限为 20 基因、100 条记录，复合候选成组；人工取消优先，自动评估不回报。
- SNP/InDel 的 AlphaMissense 校准证据、受前提保护的 LoF/人群/家系证据；ClinVar 不转换成 PP5/BP6。缺失 GQ、覆盖或祖源不能被当作通过。
- CNV Loss/Gain 完整剂量区间包含和核验后的蛋白编码基因计数；原始 HI_Max、Gene_Count、流程分类和默认 5F 不作为自动证据。
- STR 精确位点阈值、MEI/MT 精确疾病证据、印记相关 UPD 和 AR 纯合候选关联 ROH。没有对应证据时降级，不根据 HIGH、长度或异质性单独置顶。
- 自动计算器预勾选、置顶原因、证据可用性、取消及重试。Worker 单次响应 30 秒上限，取消会中止后续数据集请求。
- 回报由用户明确确认：仅所选行保存当时的 SNP/CNV 证据快照；服务端重新计分。已有人工证据及其版本保留，撤回不删除判读。报告不混入旧版服务端基线。
- CNV 保存核验原始 Parquet 的事件类型。4F/4G/4H 使用 0.15/0.30/0.45；5H 默认 0.15，保留官方范围。

## 本地验证

- 前端类型检查和生产构建通过。
- 最新前端全量回归：95 项通过；独立性能测试按环境变量显式运行，默认跳过。
- Octopus 全仓测试与服务端编译通过；新增参考包校验、否定 HPO、VCF 成员/质量及 CNV 保存回归。
- 55,393 条合成 SNP 记录搭配实际公共证据包：Node 环境初评约 203ms、候选汇总约 10ms、堆内存增加约 66MiB。不是浏览器下载或端到端性能结果。
- 公共包实际校验通过；拒绝 null 数组、错误参考、无效区间、未知 HPO 父节点及不支持的疾病关联。
