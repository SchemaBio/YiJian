# CNV 基线与样本标签修复

## 修复范围

- 基线 R1/R2 原 UI Kit 多选只有内部 open 状态，没有外部点击监听。改为应用内控件：整行点击选中/取消，外部 pointerdown 收起，Escape 优先关闭菜单，Tab 离开收起。
- 修复提交成功后 closeModal 仍读到旧 submitting=true 而不关闭的闭包问题。
- completed 数据资产逐页加载，解除原前 100 条限制；组织切换取消过期读取并清空选择。
- 读取当前 CNV 基线计费单价，按 GiB 进一法预估；无法读取配置时不伪造单价。R1/R2 增加明确配对预览；仍按用户选择顺序配对，不凭文件名自动猜测。
- 活跃基线每 15 秒读取状态，不重复下载全部资产。
- 后端保存启动未确认诊断，保留原任务身份，避免将启动异常静默视为正常提交；运行或完成后不再展示旧启动警告。
- 后端补齐名称长度、BED 非空、输入大小求和及进一法溢出保护。
- `/samples` 列表移除“已匹配”下的自动匹配/手动关联附加文字，保留状态标签。

前端类型检查、前后端生产构建通过。线上实际点击文件名称可选中、再点取消，菜单保持打开；点击菜单外部收起；Escape 不关闭父弹窗；样本列表只显示已匹配标签。
