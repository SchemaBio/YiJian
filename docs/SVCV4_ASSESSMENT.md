# SNP/InDel 双版本评定

位点展开页为：注释、证据、ACMG评定（现版）、ACMG评定（SVC v4.0试行）、人工解读、变更记录。
现版编辑器保留；人工解读不再输入理由，保存与清空仍留下审计记录。
两个评定页独立保存。浏览页签不会切换采用版本；采用动作单独要求理由。

试行页使用 Octopus 返回的固定上游 schema 引导录入，显示位点/基因/转录本/已有注释供核对。
注释频率不能自动当成 FAF，须人工确认疾病、遗传模式和证据前提。
计算在服务端完成；编辑证据后旧计算结果及确认失效，重新计算后才能保存。
分项、汇总、VUS 子类、计算详情和具体假设均可查看；采用前须确认。
只读任务可查看，不可计算修改或采用。切换位点清理草稿，同位点切换页签保留草稿。

固定规则为 `ef66faff51a265fef7b5c4e6439905f3aa540c46`，页面标注草案／非权威参考实现。
inframe_indel、non_coding 暂不支持。全部缺失为未评定；零分可以是有效 VUS-low。
现版默认采用，无需重建 Parquet。列表/筛选/CSV 读取所选版本；VUS-low/mid/high 仍兼容 VUS 筛选。
历史记录区分当前版本和报出时版本；历史报告不随切换变化。CNV 体系保持现状。

部署须同步更新 Octopus 和已有 parquet-query 容器；详见 Octopus `docs/SVCV4_ASSESSMENT.md`。
新版报告须用 report-snapshot-v2 契约并在模板显示版本与试行标记。
验证使用 TypeScript 检查、Vitest 全套及 Next.js 生产构建。
