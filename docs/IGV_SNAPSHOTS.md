# IGV 位点截图留存

需要同时发布 YiJian 与 Octopus。Octopus 启动时自动迁移 `igv_snapshots` 表；截图使用现有任务归档对象存储配置，无新增云凭据或节点。

- BAM 可用时，打开位点后仍展示实时 IGV。轨迹成功加载并绘制后，将 IGV 自身输出的 SVG 在浏览器转为 PNG，后台保存首次截图。上传已开始后关闭查看器不会中断保存。
- 对象路径：`organizations/<org>/workflows/<task>/attempts/<attempt>/_igv-snapshots/<id>.png`。
- 按组织、任务、执行批次、参考基因组和显示区间去重；同一位置不会覆盖首次截图。任务重试后的新批次不会复用旧批次截图。
- BAM 到期或不可用时优先展示截图，标明截图性质、保存时间和参考基因组；没有截图则继续展示现有 BAM 保留期限提示。不能补拍已经删除的 BAM。
- GET/POST `/api/v1/tasks/:id/results/igv/snapshot` 沿用任务访问权限。GET 参数 `locus`；POST 为 multipart 字段 `locus`、`version`、`image`。读取使用 10 分钟有效的私有对象签名 URL。
- PNG 最大 8 MiB，服务端校验格式、完整性和像素尺寸。轨迹加载失败、手动移动到其他区间、过大区间仅显示放大提示时不保存错误截图。
- 截图不参与测序证据版本计算，也不属于 BAM/BAI 定时清理范围。尚未增加独立的截图保留期限；若 COS 自身配置了整个任务目录的生命周期规则，需要保证该子目录不会被规则清除。
- 动态突变（STR）的有效坐标可直接点击进入同一查看器；缺失或无效坐标保留文本。

验证：查看器生命周期、过期回退、上传失败、错误轨迹和位点移动测试；STR 点击测试；PNG 转换测试；服务端 PNG 校验、批次隔离、证据版本稳定及无 BAM 归档时截图读取测试；TypeScript 检查与生产构建。
