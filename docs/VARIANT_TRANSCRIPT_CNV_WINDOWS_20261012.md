# 转录本注释与 CNV 图窗

## SNP/InDel

转录本列后增加“外显子/内含子”列。使用选定转录本的报告 `Location`，如 `Exon 2/20` 显示为 `Exon2`，`Intron 4/8` 显示为 `Intron4`。兼容直接提供的 `EXON`/`INTRON`；范围编号保留。缺失或仅有 Distance 时显示 `—`，不推断所在编号。

展开页“注释”新增转录本与 HGVS 分组：转录本编号、外显子/内含子编号、总数、原始位置、HGVSc、HGVSp 及变异后果。当前流水线报告字段为 `Transcript`、`Location`、`HGVS_c`、`HGVS_p`。在只提供一种总数时，另一总数按线性转录本的外显子数与内含子数相差一推算，并明确标注推算来源；没有总数时显示未提供。

## CNV Region / Exon

- ISCN 候选在标准和紧凑表格中完整换行显示，取消 160px 截断与省略号；候选注释和原始 ISCN 的含义不变。
- 点击条目同时打开右侧详情和对应图窗；标题栏中的图窗按钮紧邻详情关闭按钮左侧。
- 图窗采用独立的非模态浮窗，不锁定页面滚动，不渲染背景遮罩。通过标题拖动，也可在标题获得焦点后用方向键移动；窗口大小变化时保持关闭按钮可达。
- 点击背景或按 Esc 不关闭图窗，只通过其右上角 X 关闭。详情关闭后图窗继续保留；可从重新打开的详情标题栏打开图窗。切换条目更新信号内容，并取消过期的数据读取。
- CNV Exon 用散点替代柱形，每个有效外显子信号一个点，保留原有 weight/长度聚合、CN 计算、颜色阈值、悬停及键盘读数、转录本选择、缺失状态和原始读数表。

未改变 Parquet、COS 对象、公开 API、评定或报告。

## 验证

类型检查和 Next.js 生产构建通过。六个测试文件共 19 项通过，覆盖位置解析、总数与缺失、注释展示、图窗拖动和关闭条件、详情与图窗独立、散点输出、信号错误重试及延迟挂载绘图。
