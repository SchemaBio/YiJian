# VCF SNP/InDel 注释

数据中心支持上传 .vcf、.vcf.gz、.vcf.bgz，保留既有上传限额、分片、续传和保留期。可筛选 VCF/FASTQ。自部署可以通过“导入本地 VCF”登记服务端存储目录内的绝对路径；仍须有数据和样本管理权限。

在新建任务页或新建弹窗选择业务样本和 VCF 注释流程，再选择一个已完成且未过期的 VCF 资产。单样本文件自动选择，多样本须填写文件头中的样本名；一次仅注释一个样本。不会按业务编号猜测 VCF 内名称，也不会建立样本与 VCF 的永久关联。两个组装共用工作流，由 Octopus 配置参考资源。

流程中心提供 hg19/hg38 内置入口及组织流程，VCF 流程无需 BED 或 CNV 基线。批量 XLSX 模板追加可选 VCF数据ID、VCF内样本名列；旧 WES 模板仍有效。

结果页显示 SNP/InDel 解读、预处理与 X 性别推算统计、文件及现有报告能力，不显示未执行的 QC、CNV、MT 等模块或 BAM 下载区。规范化 VCF 和索引可供现有 IGV 使用。无有效变异时显示零记录；性别未知不会默认当作女性，也不改变业务样本登记性别。

SaaS 与 WES 使用相同计算时间费率及实际执行结算政策，初期预估 60 分钟；保留余额提示和数据保留确认。自部署不扣积分。报告生成服务的部署条件沿用原配置。

验证包含 npm run typecheck、npm test、npm run build；组件测试覆盖 VCF 文件选择、过期文件排除、错误重试、任务请求字段及仅有 SNP/InDel 的结果。真实 VEP hg19/hg38 冒烟测试需要完整参考库和已封装新脚本的执行镜像。本次不执行线上发布。
