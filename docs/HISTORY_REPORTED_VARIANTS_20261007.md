# 历史检出实现与验收（2026-10-07）

## 统计口径

仅统计用户选入回报的位点，不代表全部检出或人群频率。置顶与自动分类不进入历史。默认排除撤回；删除任务发布移除记录。相同精确位点按不同任务计数，保留成员、转录本及执行来源。参考身份或坐标不足时单独保留，不猜测合并。

## 数据与页面

原始 Parquet 不改写。Octopus 保存精简历史投影，调整、审计及投影在同一事务提交。首次回报读取经大小和 SHA 校验的原始行，拒绝客户端注释作为来源凭据。

浏览器 Worker 使用会话内存计算分组、筛选、排序、统计及分页。分页只传输数据；完整同步及多页增量接收完成后一次提交。无变化不重新计算。页面可见时每 30 秒、重新获得焦点及调整成功时同步；切换组织或退出清除缓存。页头、类型导航、列头固定，仅表格滚动。

详情保留来源身份；打开工作台前重新验证当前 attempt 和数据集版本。旧来源显示快照。审计接口首版返回最近 200 条事件。原始资源路径、签名地址及整行证据不进入历史同步。

## 验收证据

- 后端完整测试与构建通过；最终来源隔离回归测试通过。
- 前端类型检查、生产构建及 6 项引擎/性能测试通过。
- 真实数据回填 7 条、2 个数据集：SNP/InDel 有效 2 条、撤回 4 条；CNV Region 有效 1 条。重复回填写入 0 条，待核对 0 条。
- 生产接口验证：匿名 401、无效/未来游标 410、逐条传输无重复、已完成游标返回空增量、详情保持原 attempt、JSON 使用 gzip。
- 真实浏览器 Worker 的 100,000 条合成来源：原始 JSON 61,064,982 字节，传输及装载 375ms，首次查询 243ms，缓存查询 P95 44ms。主线程观测堆约 168MB，不能视为 Worker 与浏览器总内存。
- Node 引擎独立复测：100,000 条，原始 JSON 49,842,762 字节，首次查询 293ms，缓存 P95 65ms，进程堆增量约 155MB。两套夹具标识长度不同，体积不可直接比较。

用户登录后完成生产页面验收：1440、1024、768、375px 下文档没有横向溢出，表格在自身容器横向滚动；搜索 MSH2 从 2 行筛成 1 行；包含撤回显示 6 行，但有效统计仍为 2；CNV Region 显示 1 条。来源面板保留原 attempt，审计可见选入、撤回、再次选入及置顶事件，Escape 可以关闭。375px 表格需横向滚动查看完整列。
