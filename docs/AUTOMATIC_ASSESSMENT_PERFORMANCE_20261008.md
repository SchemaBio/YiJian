# 浏览器全量初评读取与传输优化

2026-10-08。本次优化及 Snappy 文件路径隔离修复已发布，真实浏览器全量初评与 SNP、两类 CNV 分页已通过，详见 `AUTOMATIC_ASSESSMENT_PRODUCTION_20261008.md`；本页性能数据来自本地开发验证，真实浏览器完整性能指标尚未测量。

## 修复与优化

- 将每 1,000 行一次的 `SELECT * / ORDER BY / LIMIT / OFFSET` 改为单次 Arrow 流，只选择规则实际需要的字段。消费完一批才继续送入 Worker，避免完整注释反复转换和复制。行身份仍使用原数据集及文件序号的 SHA256，不依赖返回顺序。
- 全量评估及跨表候选筛选完成后，以每批最多 1,000 条返回结果，代替一次复制全部评估对象。Worker 逐批释放已回传结果；全部结果接收完成且数量一致后才发布 ready。
- 记录 Worker 提前崩溃及消息反序列化失败；后续调用立即失败，避免继续等待无响应线程。证据上下文激活请求响应取消信号，读取错误或取消后等待 DuckDB 取消，再清理临时关系。
- 切换标签、回收闲置表时保护尚在打开的查询引擎，避免关闭正在承担任务全量初评的引擎。
- 位点初评查找改为 Map；状态栏展示证据加载、逐批评估、候选汇总及结果整理阶段。

不改变临床规则、证据前提、全量候选排序及候选上限；全部交互计算仍在浏览器完成。

## 本地证据

- 最终类型检查及生产构建通过；完整前端回归 101 项通过，1 项证据包性能测试默认跳过（另行指定本地固定包运行通过）。构建仍有原有 CSS `focusbutton` 和 middleware 迁移提示。
- Worker 协议测试：55,393 条合成 SNP 全量评估、汇总、分批回传，逐条核对 ID、分类及不置顶行为。约 1.6 秒，包含测试断言，不是浏览器性能指标。
- Arrow 流适配测试：138,919 条模拟记录只发起一次投影查询，每批不超过 1,000 条，逐批背压；取消与消费失败停止读取并取消查询。
- 客户端测试覆盖证据加载期间 Worker 崩溃、重试及不完整结果拒绝发布。
- 固定公共证据包 `HPO-20260901-ClinGen-20261007-Mondo-20261006-v1`，55,393 条合成 SNP：规则评估约 283ms，候选汇总约 47ms，堆增量约 68MiB。此项只测规则引擎，不含浏览器下载、WASM、真实 Arrow 传输及结果落库。
