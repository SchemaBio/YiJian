# 变异标记、质量与外部资源

更新日期：2026-10-06。

## 标记契约

- `reported`：用户最终选入回报的位点；允许撤回，不等同于报告签发。系统不会自动设置。
- `pinned`：独立的重要位点人工覆盖值。缺少覆盖时，SNP/InDel 当前有效 ACMG 分类为 `Pathogenic` 或 `Likely_Pathogenic` 时自动置顶。
- 显式 `pinned:false` 持续覆盖自动规则，包括以后分类变化；再次手动置顶可设为 true。ACMG 恢复自动基线不删除人工置顶决定。
- 其他类型仅使用人工置顶，不能据 ClinVar 标签自动置顶。
- 历史 `reviewed` 及其事件保留，不迁移成置顶，不在新表中提供复核操作。
- 置顶优先，其次仅回报位点，最后未标记位点；浏览器在完整数据集叠加调整后筛选、排序、分页和导出。原始 Parquet 不变。
- 保存复用租户、task、attempt、数据集版本隔离、乐观锁和幂等变更事件，沿用既有调整同步；无须新数据库字段。

## 详情与质量

详情首先展示人工解读、ACMG 分类。测序质量保留原始注释中的 `Quality`（VCF QUAL）、`Filter`、`Depth`、`AD`，以及存在时的 `GQ`。缺少数值显示未提供，不使用零代替；QUAL 不代替 GQ。VAF 保持样本比例的百分比展示，人群 AF 保持原始比值。
