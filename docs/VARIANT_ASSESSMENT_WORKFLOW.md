# 变异评估、计算器和采用结果

默认入口为评估总览。数据库参考、本地快速初评、AI 建议和采用结果独立展示；ClinVar 参考分类不转换为 ACMG 条款积分。AI evidence_only / insufficient_data 表示证据不足，不是作业执行失败。网络检索失败也不表示没有证据。

## 操作与保存

1. 选择 ACMG 现版或 SVC v4 实验版。查看版本不改变采用版本。
2. 人工编辑，或点击“审核并填入本版计算器”。AI 仅填入明确可映射的字段；已有人工值及冲突项保留，缺失条款不计分。SVC 只填允许的结构化上下文，不从自由文本编造数值证据，不自动确认。
3. 复核候选、强度、理由与来源。现版可直接点击“确认保存”，无需额外勾选；证据不足的草稿也可保存，由服务端保留证据不足状态，不生成分类。SVC 仍须计算后确认适用性。
4. “确认保存”在一次版本控制事务内重算、保存并采用；“仅保存本版”更新计算器，不改变采用快照，即使本版已经是当前采用版本。
5. 人工解读是后续文本记录，不参与积分。保存失败保留草稿，切换位点清空草稿。

采用快照 `adoptedACMG` 由服务端生成，包括版本、确定性分类、积分、来源、时间、证据及 AI 记录引用。旧记录不回填快照、不重新分类；首次新的计算器保存才保存其原采用状态。字段只读，客户端不能提交。浏览器覆盖层、Go/Python 查询、历史和报告读取同一采用快照。

## 数据与 AI 归档

ACMG/SVC 请求必须给出当前任务的 rowOrdinal、行 ID、attemptId 和 datasetVersion。服务端从受控的不可变任务 Parquet 读取完整注释并绑定对象 SHA256；浏览器的注释和来源声明不能建立可信数据库身份。原始字段仍在 annotationValues 中。错义等同义术语被规范化；合法 HGVS 替换符号 `>` 保留，防止 c.2015G>A 被过滤后只能进行宽泛检索，但不根据 HGVS 推断后果或借用另一转录本。

样本 VAF 来自 VAF 或双等位 AD，并记录来源；人群总 AF、群体最大 AF 和 FAF 不互换。缺少数据库版本、转录本适用性或独立验证时，保留为导入参考。现有结构化来源策略继续适用，文献可用性不是满足所有条款的统一前提；ClinVar 的既有结论本身不加分。

归档 `acmgAIResult` / `svcv4AIResult` 只接收 request ID。接口校验当前用户、租户、任务、功能和完成状态；服务端解密读取原始记录并验证位点绑定。新 ACMG 记录绑定不可变对象摘要、数据版本和执行。历史缺少绑定的记录，须读取原作业快照核对完整身份，仅标为 historicalBinding，不声称当前数据版本已验证，也不修改原作业。

AI 的 calculatorDraft 包含版本、字段路径、建议值、状态、来源 ID 和理由；它不等于审核决策。人工确认后的证据另存，历史事件记录修改前后及操作者。AI 原始记录与采用快照分开；无有效证据时仍可进入补充表单。

## 检索和实验边界

ACMG 导入任务上下文在模型首轮前主动检索准确位点，并复用检索材料，不依赖模型自行调用工具。文献查询包含基因及 DNA/蛋白 HGVS 的精确组合，保留原始材料、对象匹配和材料核实状态。仅匹配对象或找到文献不能自动证明临床条款。服务不可用、未找到记录与待核实适用性分别展示。AI 总结须解释已支持事实、缺失前提及与数据库参考不同的原因。

SVC v4 保持固定参考修订、实验标记、人工确认及已有采用门槛。没有开启正式 SVC 引擎。检索不可用时既有不计费逻辑保持。不重算历史结果、不改积分余额，不运行真实模型或分析作为发布验收。

## 回归与部署

公开 MYH3 参考为 GRCh37 17:10544634 C>T、NM_002470.4 c.2015G>A p.Arg672His；仅用于身份、错义后果和检索测试，不硬编码致病结论。

受影响前端交互、类型检查、固定来源/规则测试、Python/Go 查询导出对照及隔离 PostgreSQL 保存/并发/只读/归属测试通过后，依次切换 SepiLens、Octopus、YiJian。源代码快照中单独列出此前已有的总览预加载改动；部署不依赖未提交代码被误记成 Git HEAD。
